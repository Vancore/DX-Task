## 🧭 Концепция: Интерфейс «Единого окна»

Большинство Telegram-ботов загромождают чат десятками сообщений на каждое действие пользователя.

**DX Task** работает по принципу **Single Window UI**:
* Бот динамически обновляет одно единственное закрепленное сообщение (`send_edit`) при помощи метода `edit_message_text`.
* Сообщения с командами и текстовый ввод пользователя мгновенно удаляются после обработки (`delete_msg`).
* В результате чат превращается в чистое интерактивное приложение, работающее как нативный виджет прямо внутри мессенджера.

## 🏛 Архитектура проекта

Проект спроектирован по **трехзвенной архитектуре (Layered Architecture)** с полным разделением ответственности:

```
 ┌────────────────────────────────────────────────────────┐
 │                   ИНТЕРФЕЙСНЫЙ СЛОЙ                    │
 │                       bot.py                           │
 │  • Хэндлеры сообщений и роутинг • Оплата Stars (XTR)   │
 │  • Защита от флуда (TTLCache)   • Логика «единого окна»│
 └──────────────────────────┬─────────────────────────────┘
                            │ Вызовы UI и логики
 ┌──────────────────────────▼─────────────────────────────┐
 │                    БИЗНЕС-ЛОГИКА                       │
 │                       core.py                          │
 │  • Фильтрация и валидация ввода • Генераторы клавиатур │
 │  • Контроль тарифных лимитов    • Сборка состояний UI  │
 └──────────────────────────┬─────────────────────────────┘
                            │ Запросы чтения / записи
 ┌──────────────────────────▼─────────────────────────────┐
 │                     СЛОЙ ДАННЫХ                        │
 │                       data.py                          │
 │  • Потокобезопасный доступ     • Автоматические миграции│
 │  • Реентерабельный lock (RLock) • SQLite в режиме WAL  │
 └────────────────────────────────────────────────────────┘
```

### 1. Слой данных (`data.py`)
* **Потокобезопасность:** Реализован собственный декоратор блокировки (`@connection_lock` на базе `threading.RLock`), предотвращающий коллизии и состояние гонки при одновременных запросах.
* **Производительность:** База переведена в режим **WAL (Write-Ahead Logging)**, что обеспечивает быстрое параллельное чтение и запись без взаимных блокировок.
* **Миграции «на лету»:** Автоматическое расширение структуры таблиц (`prem_until`) при запуске бота на старых базах.

### 2. Слой логики (`core.py`)
* **Изолированность:** Полностью отвязан от отправки сетевых запросов Telegram API. Чистая доменная логика.
* **Безопасность:** Функция `check_str` экранирует синтаксические символы HTML (`<>&`), исключая поломку Telegram-разметки и инъекции.
* **Фабрика UI:** Собирает контекстные Inline-клавиатуры для выбора активного списка, отметки выполнения, удаления задач и оформления подписки.

### 3. Интерфейсный слой (`bot.py`)
* **Anti-Flood защита:** Потокобезопасный `TTLCache` (лимит 1 секунда на пользователя), отсекающий спам-клики и флуд.
* **Интеграция Telegram Stars:** Продажа подписок за валюту `XTR` через нативные инвойсы и асинхронную валидацию `pre_checkout_query`.
* **Адаптивность:** Раздельная логика работы для личных чатов (постоянное меню + единое окно) и публичных групп.

## ✨ Возможности

- **⚡ Быстрый ввод задач:** Отправьте боту любой текст в личном чате — он мгновенно превратится в задачу текущего списка без ввода команд.
- **📂 Коллекции (Списки):** Создание независимых категорий задач (*Работа, Идеи, Дом, Личное*).
- **🔄 Мгновенное переключение:** Быстрая смена активного списка задач через Inline-кнопки.
- **⭐️ Монетизация через Telegram Stars:** Поддержка 3 тарифных планов (1 месяц, 3 месяца, Навсегда).
- **🛡 Защита от флуда:** Контроль частоты запросов через in-memory кэш с автоочисткой.
- **🛠 Панель администратора:** Команда `/stats` для контроля ключевых метрик: число пользователей, подписчики Pro, размер базы.

## ⌨️ Протокол команд

### Управление списками
* `/new` — Создать новый список (сразу становится активным)
* `/lists` — Показать все существующие списки
* `/edit` — Меню смены активного списка
* `/rem` — Меню полного удаления списка вместе с задачами

### Управление задачами
* `/list` — Показать задачи текущего списка
* `/add` — Добавить задачу вручную (или просто отправьте текст)
* `/done` — Меню завершения задач (`🔘` / `✅`)
* `/del` — Меню удаления задач из текущего списка

### Система и интерфейс
* `/on` — Показать панель кнопок быстрого доступа
* `/off` — Скрыть клавиатуру
* `/fix` — Перезапустить интерфейс и вернуть меню
* `/donate` — Открыть меню подписки DX Pro
* `/help` — Справка по всем командам

### Команды администратора
* `/stats` — Мониторинг системы (пользователи, Premium, вес БД)
* `/get <user_id>` — Выдать пожизненную DX Pro подписку вручную

## 🚀 Установка и запуск

### 1. Требования
* Python 3.10+
* Токен бота от [@BotFather](https://t.me/BotFather)

### 2. Клонирование репозитория
```bash
git clone https://github.com/your-username/dxtask.git
cd dxtask
```

### 3. Создание виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
```

### 4. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 5. Конфигурация
Скопируйте файл шаблона настроек:
```bash
cp config.example.py config.py
```
Откройте созданный `config.py` и укажите ваш токен и Telegram ID администратора:
```python
TOKEN = "YOUR_BOT_TOKEN_HERE"
ADMIN_ID = 123456789  # Ваш цифровой Telegram ID (число)
```

### 6. Запуск
```bash
python bot.py
```
*Файл базы данных `data.db` создастся автоматически при первом запуске.*

## 🗄 Схема базы данных

```sql
-- Таблица пользователей и состояния подписки
CREATE TABLE users (
    user_id INTEGER PRIMARY KEY,
    active_list_id INTEGER,
    last_msg_id INTEGER,
    prem INTEGER DEFAULT 0,
    prem_until INTEGER DEFAULT 0
);

-- Таблица коллекций (списков)
CREATE TABLE list (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    title TEXT
);

-- Таблица задач
CREATE TABLE tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    list_id INTEGER,
    txt TEXT,
    done_val INTEGER DEFAULT 0
);
```
